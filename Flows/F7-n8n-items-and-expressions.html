At a glance

Items, not rows

A node input is always an array of items. Each item is { json, binary }. The node executes once for every item.

$json vs $('Node')

$json is the current item. $('Webhook').item.json reads the paired item from an earlier node in the same run.

Guard missing fields

Unresolved paths become undefined. Prefer ?? 'n/a' (or IF) so Switch / HTTP never see empty values by accident.
