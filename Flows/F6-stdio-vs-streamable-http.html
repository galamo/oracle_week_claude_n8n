F6 — stdio vs Streamable HTTP

two transports · same tools/call

Two ways a host talks to an MCP server. stdio = local child process, stdin/stdout pipes, dies with the host. Streamable HTTP = long-running /mcp endpoint, remote and shareable. Note: n8n MCP nodes do not support stdio.
