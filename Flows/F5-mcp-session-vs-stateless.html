The same hop, at a glance

Sessions stickInitialize creates a transport, stores a UUID in transports, and every later verb carries mcp-session-id. GET keeps SSE open; DELETE tears it down.

Stateless routesNo Map. Headers Mcp-Method / Mcp-Name / MCP-Protocol-Version plus body _meta make each POST self-describing — LB can bounce between replicas.

Same quiz toolslist_topics, get_question, check_answer stay identical. Only the HTTP contract around them changed in 2026-07-28.
